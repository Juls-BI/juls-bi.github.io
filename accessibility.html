Accessibility statement

I specialise in accessible Power BI, so this site is built to meet WCAG 2.2 Level AA. This statement covers the portfolio at this address.

What I've done

  • Semantic page structure with landmarks, a logical heading order and a skip link.
  • Text and interface colours checked against the 4.5:1 and 3:1 contrast thresholds.
  • Everything works with a keyboard, with a clear focus indicator that is never hidden by the sticky header.
  • Project details open in a dialog that traps focus, closes with Escape and returns focus to where you were.
  • Touch and click targets are at least 24 by 24 pixels, and nothing relies on dragging.
  • Dashboard screenshots have descriptive alt text, and the same description is repeated as text under each gallery.
  • The layout reflows down to 320 pixels wide, and text can be enlarged to 200 percent.
  • Motion is reduced if your device is set to prefer reduced motion. There is no auto-playing media.

Known limitations

  • Screenshots of Power BI reports are images, so their detail is only available through the text descriptions I provide.
  • The open source section loads repository details from GitHub when you visit. If GitHub is unavailable, a plain link to my profile is shown instead.

Last reviewed

November 2026.

Feedback

If you find a barrier on this site, please email juliana@data-tides.com and I will aim to reply within five working days.
